# Phase 1 ("Talk to it; it builds") Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Phase 1 of the autonomous engineering agent: a teammate asks in Slack (or labels a Linear issue) and gets a draft PR with passing checks. Linear is updated, events are recorded, memory works, and `stop_all` stops everything.

**Architecture:** A Python package `agent` (src layout), run as three Compose services (`core`, `worker`, `supervisor`) plus a socat `relay` to the host's Claude account proxy. Core owns SQLite state (`agent.db`, `memory.db`), Slack, Linear, dispatch, memory and core tools. Worker runs builder sessions in git worktrees and is the only holder of GitHub write credentials. All Claude sessions use the Claude Agent SDK through a `Runner` interface; tests use `FakeRunner` and fake SDK clients, so the suite runs offline.

**Tech Stack:** Python 3.12 · claude-agent-sdk 0.2.180 · slack-bolt 1.30.0 / slack-sdk 3.46.0 · aiohttp 3.14.5 · httpx 0.28.1 · SQLite (WAL, FTS5) · pytest 9.2.0 + pytest-asyncio 1.4.1.post1 · PyYAML 6 (tests only) · Docker Compose · just.

**Spec:** `docs/superpowers/specs/2026-11-12-autonomous-agent-design.md`

## Global Constraints

- Code targets **Python 3.12**. No 3.13+ features. Tests run in the `dev` Docker target (`python:3.12-slim`) through `just test`; the host has no venv.
- Pinned versions: `claude-agent-sdk==0.2.180`, `slack-bolt==1.30.0`, `slack-sdk==3.46.0`, `aiohttp==3.14.5`, `httpx==0.28.1`, `pytest==9.2.0`, `pytest-asyncio==1.4.1.post1`, `PyYAML==6.0.3`.
- Package: `src/agent/`. Tests: `tests/`, with `pythonpath = ["src"]` and `asyncio_mode = "auto"`.
- Times are stored as UTC ISO-8601 strings (`2026-11-12T05:00:00Z`). Display timezone defaults to `Asia/Singapore`.
- Token estimate everywhere: `estimate_tokens(text) = ceil(len(text) / 4 * 1.1)` (`agent.tokens`).
- Task ids are `T-0001`, `T-0002`, … Branches are `<name>/<task-id>-<slug>`.
- Proxy constants: placeholder token `sk-ant-oat01-container-via-host-proxy`. Origins `agent-core` → 18090 and `agent-worker` → 18091. Relay `172.30.0.1:28090` / `172.30.0.1:28091` on subnet `172.30.0.0/24`. Session ids sent to the proxy are lowercase UUID4 strings.
- Default limits (spec §6.3, §6.9): max_concurrent_runs 2, max_concurrent_chats 3, max_tasks_per_day 20, max_fix_cycles 2. Per-role max_turns/timeout_min: builder 150/60, tester 100/30, chat 30/5, scout 60/15, memory 10/5. At most 2 forks per run.
- Default models: builder and tester `claude-opus-5-5` (effort `high`); chat, scout and memory `claude-sonnet-5`.
- Memory budgets (briefing / look-ups): builder 2000/6000, tester 1000/3000, chat 1200/3000, scout 1500/4000, ambient 600/0. Consolidation input is capped at 8000 tokens and output at 1500.
- No secret value is ever logged, returned by a tool, put in an agent's env, or written to memory.
- Agent processes never receive GitHub write credentials. Only worker code pushes, only to `<name>/*`, never with force, and there is no merge code path (H1).
- Phase 1 status after building is `ready_for_review` with the PR left as a **draft** (Phase 2 inserts testing and marks it ready).

## Review Focus

1. **Slack retries an event.** Bolt can deliver the same `app_mention` twice, and that must not create two tasks. Test: Task 18 `test_duplicate_event_creates_one_task`.
2. **Core restarts mid-run** (crash or laptop sleep). Runs the worker no longer knows about must become `interrupted`, and the task must resume once. Test: Task 14 `test_reconcile_orphaned_run_requeues_once`.
3. **A huge issue body or Slack thread.** The builder prompt must stay bounded. Test: Task 14 `test_builder_prompt_truncates_description`.
4. **Concurrent SQLite writers** (dispatcher, pollers, Slack handlers in one process). These must not raise "database is locked". Test: Task 3 `test_connection_sets_wal_and_busy_timeout`.
5. **Emoji, non-ASCII or empty task titles.** These must still give a valid branch name. Test: Task 12 `test_slugify_handles_unicode_and_empty`.
