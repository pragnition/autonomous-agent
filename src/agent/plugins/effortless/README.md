# effortless (vendored)

Picks the reasoning effort for every prompt: a Haiku judge reads the prompt and sets the effort for that turn's
requests. Every agent session loads it next to the core plugin.

Source: https://github.com/HeyCubit/effortless at e5c590dfd9402244ea66a8bf795d1cb86d1df7b9 (version 1.72.0), MIT.
Only the files the mod runs are copied, unchanged. To update, copy the same files from a newer commit.
